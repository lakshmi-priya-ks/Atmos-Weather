# Atmos – Weather Dashboard

Atmos is a responsive weather dashboard built using React. It provides current weather conditions, hourly forecasts, and a five-day weather outlook through a clean and intuitive interface.

## Live Demo

[View Atmos Weather Dashboard](https://atmos-weather-rose.vercel.app)

## Features

- Search weather information by city or location.
- View current temperature and weather conditions.
- Switch between Celsius and Fahrenheit.
- Detect the user's current location.
- View humidity, wind speed, atmospheric pressure, and feels-like temperature.
- Explore hourly weather forecasts.
- View five-day weather forecasts.
- Check sunrise and sunset timings.
- Access recently searched locations.
- Responsive interface for different screen sizes.

## Technologies Used

- React
- JavaScript
- Vite
- CSS
- Lucide React

## APIs Used

- Open-Meteo Weather API – Weather forecasts and current weather information.
- Open-Meteo Geocoding API – Location search.
- Photon API – Alternative location search.
- BigDataCloud Reverse Geocoding API – Identifying the user's location from GPS coordinates.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/lakshmi-priya-ks/Atmos-Weather.git
```

Navigate to the project directory:

```bash
cd Atmos-Weather
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Build

To create a production build:

```bash
npm run build
```
